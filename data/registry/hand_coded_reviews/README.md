# Researcher hand-coded reviews

The Fieldnotes website submits small batches through the reviewer's GitHub
sign-in. A trusted workflow accepts only configured researchers, validates the
payload against existing school/program identities, and saves an immutable
JSON journal here. No publisher page is represented as an archived snapshot.

Every decision retains `hand_coded`, reviewer, authenticated GitHub account,
submission time, applicable school year, source year when stated, evidence URL,
notes, optional quote, coding method, and the exact program sites changed.
Explicit source statements and researcher interpretations remain distinct.
New source observations do not overwrite prior observations. The latest
hand-coded selection wins only for that field, program and reviewed year.

Language-allocation entries are source-reported labels; they do not invent named
language shares, a full-day denominator, or tested-cohort exposure. A mixed
delivery model requires explanatory notes. A parked case remains unresolved.
Changes are bounded to the reviewed year; an upper use bound does not establish
a program end date. Assessment collections and the frozen national baseline
remain unchanged.
