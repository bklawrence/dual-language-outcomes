# Five-state coverage report

Reference year: **2026–27**. Research date: **November 3, 2026** (America/Chicago; source-access timestamps are November 4 UTC).

**This is a partial, source-documented inventory, not an established statewide census.** A source being accessible today does not establish operation in the target school year.
